# F&F 적합성 점수화 루브릭

`src/core/score.py` 가 이 기준으로 캐릿 수집물을 채점한다.

## 브랜드
- **패션/스포츠:** MLB · MLB Kids · Discovery Expedition · Duvetica · Sergio Tacchini
- **뷰티/향기:** F&CO · 헤트라스
- ※ **MLB는 중국 사업이 핵심** → 중국/글로벌 신호 가중.

## 타깃
10대~50대 전 세대 (MZ 한정 아님). 캐릿이 MZ 중심이라 40~50대는 추후 소스 보강 필요.

## 카테고리 범위
패션 · 스트릿 · 스포츠 · 아웃도어 · 액세서리 **+ 뷰티 · 향기 · 코스메틱**

## 점수화 6기준 (가중)
| 기준 | 가중 | 내용 |
|---|---|---|
| 시점/선행성 | 25 | `유행예감` > `유행중` > `유행지남`. 마이크로 전광판 신착 = 최우선 |
| 실행 가능성 | 25 | 콜라보/캠페인/상품 기획으로 옮길 수 있나 |
| 카테고리 적합 | 20 | 위 카테고리 범위와 겹치나 |
| 브랜드 매칭 | 20 | 7개 브랜드 중 어디에 연결되나 |
| 타깃 적합 | 10 | 10~50대 중 어느 세대 |
| 브랜드 리스크 | 감점 | 논란·부정 이슈와 엮이면 감점 |

## 출력 Tier
- 🔥 Tier 1 우선 포착 (표: 트렌드·점수·시점·브랜드·추천액션)
- ✅ Tier 2 주목
- 📌 Tier 3 실행 레퍼런스
- ⏸ Tier 4 낮음 (디저트·음식·일반 밈 등 F&F 무관)
