Q. 시트에 오늘 새 줄이 없어요

  1. 오늘 아침 8시에 컴퓨터가 꺼져 있었다면 → 그게 원인이에요. 아래 명령으로 지금 한 번 돌려주세요 (10~25분 걸림): 
    venv\Scripts\python.exe src\core\run_daily.py
  2. 끝나면 시트를 새로고침해서 새 줄이 생겼는지 확인. 몇 번을 다시 돌려도 중복으로 쌓이지 않으니 걱정 마세요.
  3. 그래도 안 되면 → 아래 "잘 모르겠어요" 카드로.

Q. "캐릿 로그인이 풀렸다"고 해요 (수집 실패)

캐릿은 유료 사이트라 가끔 로그인이 풀립니다. 이때만 사람 손이 한 번 필요해요.

  1. 아래 명령을 실행 → 브라우저가 저절로 열리며 로그인을 진행합니다: 
    venv\Scripts\python.exe src\service\setup_profile.py
  2. "인증번호를 입력하라"고 하면 → 캐릿 계정 이메일로 온 숫자 코드를 확인하고, 프로젝트 폴더 안에 .otp라는 이름의 파일을 만들어 그 숫자만 적어 저장하세요. (메모장에서 저장 시 파일 이름을 ".otp" 따옴표 포함으로 저장하면 됩니다)
  3. "기기가 꽉 찼다"는 화면이 나오면 → 화면에서 안 쓰는 기기를 삭제하고 계속 진행.
  4. 끝나면 위의 "시트에 새 줄이 없어요" 카드의 명령으로 오늘 치를 한 번 돌려주세요.

⚠️ 진행 중에 열린 브라우저 창을 강제로 닫지 마세요 — 로그인이 저장되기 전에 날아갑니다.

Q. 잘 모르겠어요 / 다른 오류가 떠요

  1. 이 컴퓨터에 Claude Code(AI 도우미)가 설치되어 있어요. 프로젝트 폴더에서 Claude Code를 열고 /trend-status 라고 입력하면, AI가 스스로 검사하고 무엇이 문제인지·어떻게 고치는지 알려줍니다.
  2. 또는 그냥 한국어로 물어봐도 됩니다: "오늘 시트에 글이 안 올라왔어, 확인해줘"
  3. AI로도 해결이 안 되면 개발 담당자에게 src\data\run.log 파일(실행 기록)과 함께 문의하세요.

1

파일·계정 넘겨받기

인계받을 것은 두 묶음입니다.

묶음내용받는 방법
① 프로젝트 폴더시스템의 모든 프로그램과 설명서. 과거 수정 이력까지 담겨 있음전임자에게 깃허브 저장소 초대를 받아 git clone (4절 1번)
② (선택) 과거 데이터비밀 열쇠는 받을 게 없습니다 — 캐릿 계정(1-A절)·로봇 열쇠 gcp_sa.json(1-C절)·Gemini AI 열쇠(1-D절) 전부 새 담당자가 직접 만들고, .env는 저장소의 .env.example을 복사해 채우면 됩니다(시트 주소는 미리 채워져 있음). 받을 것은 (선택) 과거 데이터뿐 · (선택) trends.db와 src\data 폴더(그동안 모은 자료 — 받으면 첫 실행 때 AI 비용 절약)반드시 1:1 메시지나 USB로만. 이메일·단체방 금지

깃허브에 들어있지 않은 것: venv 폴더, profile 폴더(캐릿 로그인 상태), 아침 8시 자동 실행 설정 — 없는 게 정상이고, 모두 4절 설치 과정에서 새로 만들어집니다.

인계 원칙 = 모든 계정·열쇠를 새 담당자 명의로 — ① 캐릿: 새 유료 계정 가입(1-A절, 전임자 계정 이관 안 함), ② 구글 시트: 소유권 이전(1-B절) + 시트에 글 쓰는 로봇 계정 새로 생성(1-C절), ③ Gemini AI 열쇠 직접 발급(1-D절). 아래에 "어디서 무엇을 바꾸는지"까지 절차로 정리했습니다. 전부 새 담당자 소유가 되어야, 전임자가 퇴사해도 시스템이 계속 살아있습니다.

1-A. 캐릿 — 새 계정 만들어 기기 등록 ★

캐릿은 유료 회원제 + 기기 4대 제한이 있는 사이트입니다. 인계 방침: 전임자 계정을 물려받지 않고, 새 담당자 명의의 새 계정으로 시작합니다. 관련 설정은 딱 두 곳:

무엇어디에 있나바꾸는 법
계정 아이디·비밀번호프로젝트 폴더의 .env 파일 안 CAREET_EMAIL / CAREET_PASSWORD 두 줄메모장으로 열어 값만 바꾸면 끝
기기 등록(로그인 상태)profile 폴더 (시스템 전용 브라우저)직접 못 고침 — 아래 등록 절차가 만들어 줌

절차 — 새 계정으로 새 컴퓨터 등록하기:

  1. 캐릿 새 계정 가입 + 유료 멤버십 결제 — careet.net에서 새 담당자 명의로 가입하고 멤버십을 결제합니다. (회사 비용이면 결제 수단부터 확인)
  2. .env 파일을 메모장으로 열어 CAREET_EMAIL / CAREET_PASSWORD 두 줄을 새 계정 값으로 교체.
  3. 아래 명령을 실행하면 브라우저가 저절로 열리며 새 계정으로 로그인합니다: 
    venv\Scripts\python.exe src\service\setup_profile.py
  4. 새 계정 이메일로 온 인증번호를 프로젝트 폴더 안에 .otp라는 파일로 저장(내용=숫자만)하면 자동으로 등록이 끝납니다. 새 계정이라 기기 슬롯이 비어 있어 기기 삭제 과정 없이 바로 등록돼요.
  5. 확인: ☀️ 탭의 "시트에 새 줄이 없어요" 명령을 한 번 돌려서 성공하면 완료. ⚠️ 진행 중 브라우저 창을 강제로 닫지 마세요.

전임자 마무리: 자기 캐릿 계정 마이페이지에서 자동화 기기(trend-agent)를 삭제하고, 자기 멤버십은 해지 여부를 결정하세요 (두 계정 결제가 겹치는 기간이 없는지 확인).

1-B. 구글 시트 — 쌓인 데이터와 계정 넘기기 ★

먼저 구조 이해: 시트에 매일 글을 쓰는 건 사람 계정이 아니라 "로봇 계정"입니다(열쇠 = gcp_sa.json 파일). 그래서 시트 주인이 누구든, 그 시트에 로봇이 초대되어 있고 + .env에 적힌 시트 주소가 맞기만 하면 시스템은 계속 돌아갑니다. 이관은 이 두 가지를 맞추는 일이에요.

절차 — 시트 주인만 바꾸기 (소유권 이전):

  1. 시트 오른쪽 위 공유 → 새 담당자를 편집자로 추가 → 그 사람 옆 메뉴에서 "소유권 이전" → 새 담당자가 이메일에서 수락.
  2. 끝! 시트 주소가 안 바뀌니 아무 파일도 고칠 필요 없고, 쌓인 데이터·메모 전부 그대로입니다. 전임자는 이후 시트에서 나가도 무방해요.
  3. 확인: 아래 명령을 실행해 "추가예정 0"이 나오면 연결도 정상입니다: 
    venv\Scripts\python.exe src\service\sheets_push.py --dry

참고: 개인 Gmail ↔ 회사 계정처럼 계정 종류가 다르면 구글이 소유권 이전을 막는 경우가 있습니다. 그때는 Claude Code에 "시트 소유권 이전이 안 돼"라고 요청해 대안을 안내받으세요.

⚠️ 새 담당자에게 꼭 전할 한 마디 — 시트 공유 목록에 있는 ...iam.gserviceaccount.com 계정은 시스템 로봇이니 절대 삭제 금지. 모르는 계정 같아서 정리하다 지우면 그날부터 시트에 글이 안 올라옵니다.

1-C. 로봇 계정도 새로 만들기 — gcp_sa.json 교체 ★

시트에 글을 쓰는 로봇 계정도 전임자의 구글 계정에서 만든 것이므로, 새 담당자의 구글 계정으로 새로 만들어 교체합니다. 한 번만 하면 되는 작업이고, 화면 클릭 몇 번이면 10분 안에 끝나요.

  1. 구글 클라우드 콘솔 접속 — 새 담당자 구글 계정으로 console.cloud.google.com 로그인 → 화면 상단의 프로젝트 선택 → "새 프로젝트"(이름 예: trend-agent) 만들고 그 프로젝트를 선택.
  2. Sheets API 켜기 — 왼쪽 메뉴 "API 및 서비스" → "라이브러리"에서 Google Sheets API 검색 → "사용 설정" 클릭. (이 시스템은 Sheets API 하나만 쓰면 됩니다)
  3. 로봇 계정 만들기 — "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기" → "서비스 계정" 선택 (이름 예: trend-bot) → 권한 등 나머지 단계는 건너뛰고 "완료".
  4. 열쇠(JSON) 내려받기 — 방금 만든 서비스 계정 이름 클릭 → "키" 탭 → "키 추가" → "새 키 만들기" → JSON 선택 → 키 파일이 자동 다운로드됩니다.
  5. 파일 교체 — 내려받은 파일의 이름을 gcp_sa.json으로 바꿔 프로젝트 폴더 맨 위에 넣기. .env는 고칠 필요 없습니다(파일 이름만 맞으면 됨).
  6. 시트에 새 로봇 초대 — gcp_sa.json을 메모장으로 열어 client_email 값(...iam.gserviceaccount.com으로 끝나는 주소)을 복사 → 구글 시트의 공유에 이 주소를 편집자로 추가. 전임자의 옛 로봇 주소는 이때 공유 목록에서 제거하면 됩니다.
  7. 확인 — 아래 명령이 오류 없이 "추가예정" 건수를 보여주면 연결 성공: 
    venv\Scripts\python.exe src\service\sheets_push.py --dry

중간에 막히면 Claude Code에 "gcp_sa.json 새로 만드는 중인데 ○단계에서 막혔어"라고 물어보세요. 콘솔 화면은 종종 바뀌지만 흐름(프로젝트 → Sheets API → 서비스 계정 → JSON 키 → 시트 공유)은 같습니다.

1-D. Gemini AI 열쇠도 직접 발급 ★

글을 요약·분석하는 AI(Gemini)의 열쇠도 전임자 것을 물려받지 않고 새 담당자 구글 계정으로 직접 발급합니다. 1분이면 끝나요.

  1. aistudio.google.com 접속 → 새 담당자 구글 계정으로 로그인.
  2. "Get API key" / "API 키 만들기" 버튼 클릭 → 키 생성 → 복사.
  3. 프로젝트 폴더의 .env 파일을 메모장으로 열어 GEMINI_API_KEY= 뒤에 붙여넣고 저장.

무료 등급으로도 동작하지만 하루 사용량 제한이 있어, 운영 중 분석 실패가 자주 보이면 구글 클라우드 결제 연결로 상향하면 됩니다. 이 키도 비밀 — 단체방·이메일 공유 금지.

2

시스템이 매일 하는 일 (구조)

매일 아침 8시, 컴퓨터가 4가지 일을 순서대로 합니다:

  1. 글 모으기 — 13개 사이트에서 최근 3주 안의 트렌드 글을 수집. (캐릿이 첫 단계라, 캐릿 로그인이 풀리면 여기서 멈춤)
  2. AI 요약 — 글마다 본문과 사진을 AI(Gemini)가 읽고 한줄요약·토픽·브랜드·마케팅 포인트를 뽑음. 한 번 요약한 글은 기억해 두므로, 새 글에만 비용이 듭니다.
  3. 장부에 기록 — 컴퓨터 안의 누적 장부(trends.db)에 저장. 여기는 지워지지 않고 계속 쌓입니다.
  4. 시트에 올리기 — 장부에서 시트에 아직 없는 새 글만 골라 맨 아래에 추가. 기존 줄은 절대 안 건드림.

4

새 컴퓨터에 설치하기

순서대로 따라 하면 30분~1시간이면 끝납니다. 명령은 전부 복사해 붙여넣기 (실행법: ☀️ 탭 3번). 막히면 Claude Code에 "설치 이어서 도와줘"라고 하세요.

  1. 깃허브에서 프로젝트 받기 — 전임자에게 저장소 초대(접근 권한)를 받은 뒤, 원하는 위치(예: C:\Users\내이름\Agent)에서: 
    git clone <저장소 주소>
  2. 비밀 파일 넣기 — 폴더 안의 .env.example을 복사해 .env로 저장하고, 캐릿 새 계정(1-A절)과 직접 발급한 Gemini AI 열쇠(1-D절)를 채우기(시트 주소는 이미 채워져 있음). gcp_sa.json은 1-C절 절차로 직접 만들어 폴더 맨 위에, (받았다면) trends.db·src\data 폴더도 제자리에.
  3. 실행 환경 설치 — 아래 세 줄을 순서대로: 
    python -m venv venv
venv\Scripts\pip.exe install -r requirements.txt
venv\Scripts\playwright.exe install chromium
  4. 캐릿 기기 등록 — 1-A절의 절차 그대로 (제일 까다로운 단계).
  5. 시험 운전 — 전체를 한 번 수동 실행하고, 시트에 잘 올라가는지 확인: 
    venv\Scripts\python.exe src\core\run_daily.py
  6. 매일 아침 8시 자동 실행 등록 — 관리자 권한 PowerShell에서, 첫 줄의 경로만 실제 폴더 위치로 바꿔 실행: 
    $ROOT = "C:\Users\<내이름>\Agent\trend-monitoring-agent"
$PY = "$ROOT\venv\Scripts\python.exe"
schtasks /Create /F /TN FF-Trend-Daily /SC DAILY /ST 08:00 /TR "`"$PY`" `"$ROOT\src\core\run_daily.py`""
  7. 다음날 아침 확인 — 시트에 오늘 날짜 새 줄이 있으면 성공. 전임자 컴퓨터의 자동 실행은 꺼달라고 요청 (schtasks /Delete /F /TN FF-Trend-Daily).
기억할 것: 자동 실행은 아침 8시에 컴퓨터가 켜져 있고 로그인된 상태여야 돕니다. 꺼뒀던 날은 다음 실행 때 최근 3주치에서 놓친 글을 알아서 보충합니다.
5

바꿀 수 있는 설정들

무엇을 바꿀 수 있고, 직접 할 수 있는지 / AI에게 부탁할 일인지로 정리했습니다. AI에게 부탁하는 법: 프로젝트 폴더(git clone 받은 위치, 예: C:\Users\내이름\Agent\trend-monitoring-agent)에서 터미널을 열어 claude를 실행하고, 표의 문장을 그대로 말하면 됩니다. /로 시작하는 것은 스킬(단축 명령) — 대화창에 그대로 입력하면 정해진 절차를 자동으로 수행하며, 프로젝트 폴더에 포함되어 있어 clone만 하면 바로 쓸 수 있습니다.

시트 관련 규칙 (다시 한 번)

  • 자동 칸 A~N: 순서 바꾸기·중간 삭제 금지. 사람 칸(메모 등)은 O열부터 오른쪽으로 자유롭게.
  • 여러 사람 컴퓨터에서 같은 시트에 올려도 안전합니다(중복 확인 후 추가). "수집자" 칸으로 누가 모았는지 구분돼요.
  • AI 요약이 만든 내용이 마음에 안 들면 시트에서 직접 고쳐도 됩니다 — 시스템이 덮어쓰지 않아요.

보안 규칙

  • 캐릿은 유료 콘텐츠 — 모은 본문은 내부 분석용으로만. 외부 공유·원문 복사 금지. (그래서 시트에도 본문 전문은 안 올라갑니다)
  • .env·gcp_sa.json은 비밀 열쇠 — 이메일·단체방 전송 금지, 주고받을 땐 1:1로만.
  • 시트 공유 목록의 로봇 계정(...iam.gserviceaccount.com) 삭제 금지. (단, 1-C절에서 새 로봇으로 교체를 마친 뒤 옛 로봇을 지우는 것은 예외)
  • 인계가 끝나면 전임자가 할 마무리: 자기 컴퓨터의 자동 실행 끄기 → 자기 캐릿 계정의 기기 목록에서 자동화 기기 삭제 → 자기 캐릿 멤버십 해지 여부 결정 (계정은 넘기지 않음).
