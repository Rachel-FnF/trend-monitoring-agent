트렌드 자동 수집 시스템 · 인수인계 (비개발자용)

트렌드 시트 안내서

이 컴퓨터는 매일 아침 8시에 혼자 일합니다. 캐릿·뉴닉·Vogue 등 13곳에서 트렌드 글을 모아 AI가 요약하고, 결과를 구글 시트에 자동으로 쌓아줍니다. 여러분이 할 일은 거의 없어요 — 이 문서 한 장이면 충분합니다.

1

매일 할 일 — 딱 한 가지

☀️ 아침에 구글 시트를 열고, 맨 아래에 오늘 날짜의 새 줄이 생겼는지 본다.

새 줄이 있으면 → 끝! 오늘은 아무것도 안 해도 됩니다.
새 줄이 없으면 → 아래 3번 "문제가 생겼어요"를 보세요.

※ 구글 시트 주소는 인계자에게 받아서 브라우저 즐겨찾기에 저장해 두세요. 시트의 "DB등록일" 칸이 오늘 날짜인 줄이 새로 들어온 글입니다.

시트는 자유롭게 써도 됩니다

  • 글마다 메모·활용 아이디어·상태를 적는 칸(O열 이후)이 있어요. 마음껏 쓰세요.
  • 이미 들어온 줄의 내용을 고쳐도 괜찮습니다. 시스템은 새 글만 아래에 추가할 뿐, 있는 줄은 절대 건드리지 않아요. 여러분이 쓴 메모가 지워질 일은 없습니다.
  • 딱 하나만 지켜주세요: 왼쪽 A~N열의 순서를 바꾸거나 중간 열을 삭제하지 않기. (시스템이 왼쪽부터 순서대로 채우기 때문) 새 칸이 필요하면 항상 오른쪽 끝에 추가하세요.
2

컴퓨터 규칙 — 두 가지만

  • 아침 8시에 이 컴퓨터가 켜져 있고, 담당 계정으로 로그인되어 있어야 자동 실행이 돕니다. (잠금 화면은 괜찮아요. 꺼져 있거나 로그아웃 상태면 안 돌아요.)
  • 휴가 등으로 컴퓨터를 꺼뒀다면? 괜찮습니다. 최근 3주치를 기억하고 있어서, 다음에 실행될 때 놓친 글을 자동으로 보충해요. 다만 그날 아침엔 시트에 새 줄이 없겠죠.
3

문제가 생겼어요 — 상황별 해결

💻 명령을 실행하는 법 (아래 카드들에서 사용)
① 바탕화면에서 이 프로젝트 폴더(trend-monitoring-agent)를 연다 → ② 폴더 위쪽 주소창을 클릭하고 powershell이라고 입력 후 엔터 → ③ 검은 창이 뜨면 아래 명령을 복사해 붙여넣고(마우스 우클릭=붙여넣기) 엔터.

Q. 시트에 오늘 새 줄이 없어요

  1. 오늘 아침 8시에 컴퓨터가 꺼져 있었다면 → 그게 원인이에요. 아래 명령으로 지금 한 번 돌려주세요 (10~25분 걸림): 
    venv\Scripts\python.exe src\core\run_daily.py
  2. 끝나면 시트를 새로고침해서 새 줄이 생겼는지 확인. 몇 번을 다시 돌려도 중복으로 쌓이지 않으니 걱정 마세요.
  3. 그래도 안 되면 → 아래 "잘 모르겠어요" 카드로.

Q. "캐릿 로그인이 풀렸다"고 해요 (수집 실패)

캐릿은 유료 사이트라 가끔 로그인이 풀립니다. 이때만 사람 손이 한 번 필요해요.

  1. 아래 명령을 실행 → 브라우저가 저절로 열리며 로그인을 진행합니다: 
    venv\Scripts\python.exe src\service\setup_profile.py
  2. "인증번호를 입력하라"고 하면 → 캐릿 계정 이메일로 온 숫자 코드를 확인하고, 프로젝트 폴더 안에 .otp라는 이름의 파일을 만들어 그 숫자만 적어 저장하세요. (메모장에서 저장 시 파일 이름을 ".otp" 따옴표 포함으로 저장하면 됩니다)
  3. "기기가 꽉 찼다"는 화면이 나오면 → 화면에서 안 쓰는 기기를 삭제하고 계속 진행.
  4. 끝나면 위의 "시트에 새 줄이 없어요" 카드의 명령으로 오늘 치를 한 번 돌려주세요.

⚠️ 진행 중에 열린 브라우저 창을 강제로 닫지 마세요 — 로그인이 저장되기 전에 날아갑니다.

Q. 잘 모르겠어요 / 다른 오류가 떠요

  1. 이 컴퓨터에 Claude Code(AI 도우미)가 설치되어 있어요. 프로젝트 폴더에서 Claude Code를 열고 /trend-status 라고 입력하면, AI가 스스로 검사하고 무엇이 문제인지·어떻게 고치는지 알려줍니다.
  2. 또는 그냥 한국어로 물어봐도 됩니다: "오늘 시트에 글이 안 올라왔어, 확인해줘"
  3. AI로도 해결이 안 되면 개발 담당자에게 src\data\run.log 파일(실행 기록)과 함께 문의하세요.
4

해도 되는 것 · 하면 안 되는 것

✓ 해도 됩니다
  • 시트에 메모·상태 자유롭게 쓰기 (O열 이후)
  • 시트의 기존 줄 내용 고치기
  • 같은 날 여러 번 수동 실행 (중복 안 생김)
  • 컴퓨터 잠금 화면으로 두기
✕ 하면 안 됩니다
  • 시트 A~N열 순서 바꾸기·중간 열 삭제
  • .env·gcp_sa.json 파일을 메일·메신저로 외부에 보내기 (비밀 열쇠예요 — 인계 시에는 반드시 1:1 DM으로만)
  • 캐릿 글 본문을 회사 밖으로 공유·복붙 (유료 콘텐츠, 내부 분석용만)
  • 프로젝트 폴더 안 profile·venv·src\data 폴더 삭제
