Q. 시트에 오늘 새 줄이 없어요

  1. 오늘 아침 8시에 컴퓨터가 꺼져 있었다면 → 그게 원인이에요. 아래 명령으로 지금 한 번 돌려주세요 (10~25분 걸림): 
    venv\Scripts\python.exe src\core\run_daily.py
  2. 끝나면 시트를 새로고침해서 새 줄이 생겼는지 확인. 몇 번을 다시 돌려도 중복으로 쌓이지 않으니 걱정 마세요.
  3. 그래도 안 되면 → 아래 "잘 모르겠어요" 카드로.

Q. "캐릿 로그인이 풀렸다"고 해요 (수집 실패)

캐릿은 유료 사이트라 가끔 로그인이 풀립니다. 이때만 사람 손이 한 번 필요해요.

  1. 아래 명령을 실행 → 브라우저가 저절로 열리며 로그인을 진행합니다: 
    venv\Scripts\python.exe src\service\setup_profile.py
  2. "인증번호를 입력하라"고 하면 → 캐릿 계정 이메일로 온 숫자 코드를 확인하고, 프로젝트 폴더 안에 .otp라는 이름의 파일을 만들어 그 숫자만 적어 저장하세요. (메모장에서 저장 시 파일 이름을 ".otp" 따옴표 포함으로 저장하면 됩니다)
  3. "기기가 꽉 찼다"는 화면이 나오면 → 화면에서 안 쓰는 기기를 삭제하고 계속 진행.
  4. 끝나면 위의 "시트에 새 줄이 없어요" 카드의 명령으로 오늘 치를 한 번 돌려주세요.

⚠️ 진행 중에 열린 브라우저 창을 강제로 닫지 마세요 — 로그인이 저장되기 전에 날아갑니다.

Q. 잘 모르겠어요 / 다른 오류가 떠요

  1. 이 컴퓨터에 Claude Code(AI 도우미)가 설치되어 있어요. 프로젝트 폴더에서 Claude Code를 열고 /trend-status 라고 입력하면, AI가 스스로 검사하고 무엇이 문제인지·어떻게 고치는지 알려줍니다.
  2. 또는 그냥 한국어로 물어봐도 됩니다: "오늘 시트에 글이 안 올라왔어, 확인해줘"
  3. AI로도 해결이 안 되면 개발 담당자에게 src\data\run.log 파일(실행 기록)과 함께 문의하세요.

파일·계정 넘겨받기

인계받을 것은 두 묶음입니다.

묶음내용받는 방법

인계에서 가장 중요한 두 가지 = 계정 넘기기 — ① 캐릿 유료 계정, ② 구글 시트(전임자 개인 계정으로 만들어져 있음). 아래에 "어디서 무엇을 바꾸는지"까지 절차로 정리했습니다. 둘 다 새 담당자 소유로 옮겨야, 전임자가 퇴사해도 시스템이 계속 살아있습니다.

1-A. 캐릿 계정과 기기 등록 ★

캐릿은 유료 회원제 + 기기 4대 제한이 있는 사이트입니다. 관련 설정은 딱 두 곳:

무엇어디에 있나바꾸는 법
계정 아이디·비밀번호프로젝트 폴더의 .env 파일 안 CAREET_EMAIL / CAREET_PASSWORD 두 줄메모장으로 열어 값만 바꾸면 끝
기기 등록(로그인 상태)profile 폴더 (시스템 전용 브라우저)직접 못 고침 — 아래 등록 절차가 만들어 줌

새 컴퓨터에서 기기 등록하기 (계정을 그대로 쓰는 경우):

  1. 아래 명령을 실행하면 브라우저가 저절로 열리며 로그인합니다. 기기 4대가 꽉 차 있으면 알아서 한 자리를 비우고 인증번호 발송까지 진행해요: 
    venv\Scripts\python.exe src\service\setup_profile.py
  2. 캐릿 계정 이메일로 온 인증번호를 프로젝트 폴더 안에 .otp라는 파일로 저장(내용=숫자만)하면 자동으로 등록이 끝납니다.
  3. 확인: ☀️ 탭의 "시트에 새 줄이 없어요" 명령을 한 번 돌려서 성공하면 완료. ⚠️ 진행 중 브라우저 창을 강제로 닫지 마세요.

계정 자체를 새 담당자 명의로 바꾸는 경우 (한 단계 추가):

  1. .env 파일의 CAREET_EMAIL/CAREET_PASSWORD를 새 계정 값으로 교체.
  2. profile 폴더를 삭제 — 옛 계정의 로그인 정보가 남아 있어서, 지우지 않으면 계속 옛 계정으로 접속합니다. (불안하면 삭제 대신 profile_old로 이름을 바꿔 백업)
  3. 위의 "기기 등록하기" 1~3 진행. 인증번호는 이제 새 계정의 이메일로 옵니다.
  4. 마무리: 옛 계정으로 캐릿에 로그인해 마이페이지에서 예전 기기(trend-agent)를 삭제해 자리를 정리.

1-B. 구글 시트 — 쌓인 데이터와 계정 넘기기 ★

먼저 구조 이해: 시트에 매일 글을 쓰는 건 사람 계정이 아니라 "로봇 계정"입니다(열쇠 = gcp_sa.json 파일). 그래서 시트 주인이 누구든, 그 시트에 로봇이 초대되어 있고 + .env에 적힌 시트 주소가 맞기만 하면 시스템은 계속 돌아갑니다. 이관은 이 두 가지를 맞추는 일이에요.

방법 A — 시트 주인만 바꾸기 (권장, 제일 간단)

  1. 시트 오른쪽 위 공유 → 새 담당자를 편집자로 추가 → 그 사람 옆 메뉴에서 "소유권 이전" → 새 담당자가 이메일에서 수락.
  2. 끝! 시트 주소가 안 바뀌니 아무 파일도 고칠 필요 없고, 쌓인 데이터·메모 전부 그대로입니다. 전임자는 이후 시트에서 나가도 무방해요.
  3. 단, 개인 Gmail → 회사 계정처럼 종류가 다르면 구글이 소유권 이전을 막을 수 있음 → 방법 B로.

방법 B — 새 계정에서 사본 만들기 (방법 A가 안 될 때)

  1. 새 담당자 계정으로 로그인한 브라우저에서 기존 시트를 열고 파일 → 사본 만들기. 반드시 '사본'이어야 합니다 — 빈 시트로 시작하면 자동 데이터(A~N열)는 시스템이 다시 채워주지만, 사람이 손으로 쓴 메모(O열 이후)는 영영 사라져요.
  2. 새 시트의 공유에 로봇 계정을 편집자로 초대 — 로봇의 이메일 주소는 gcp_sa.json 파일을 메모장으로 열면 client_email 항목에 있습니다 (...iam.gserviceaccount.com으로 끝남).
  3. .env 파일의 SHEETS_TREND_ID 값을 새 시트의 주소 ID로 교체 — 시트 URL에서 /d/와 /edit 사이의 긴 문자열입니다.
  4. 확인: 아래 명령을 실행해 "추가예정 0"이 나오면 완벽 (기존 데이터를 전부 알아본 것): 
    venv\Scripts\python.exe src\service\sheets_push.py --dry
⚠️ 새 담당자에게 꼭 전할 한 마디 — 시트 공유 목록에 있는 ...iam.gserviceaccount.com 계정은 시스템 로봇이니 절대 삭제 금지. 모르는 계정 같아서 정리하다 지우면 그날부터 시트에 글이 안 올라옵니다.

참고(급하지 않음): 로봇 계정 자체도 전임자의 구글 계정에서 만든 것이라, 완전히 독립하려면 나중에 새 담당자 계정으로 로봇을 새로 만들어 gcp_sa.json을 교체하면 됩니다. Claude Code에 "구글 서비스계정 새로 만들어서 교체하고 싶어"라고 요청하면 안내해 줍니다.

2

시스템이 매일 하는 일 (구조)

매일 아침 8시, 컴퓨터가 4가지 일을 순서대로 합니다:

  1. 글 모으기 — 13개 사이트에서 최근 3주 안의 트렌드 글을 수집. (캐릿이 첫 단계라, 캐릿 로그인이 풀리면 여기서 멈춤)
  2. AI 요약 — 글마다 본문과 사진을 AI(Gemini)가 읽고 한줄요약·토픽·브랜드·마케팅 포인트를 뽑음. 한 번 요약한 글은 기억해 두므로, 새 글에만 비용이 듭니다.
  3. 장부에 기록 — 컴퓨터 안의 누적 장부(trends.db)에 저장. 여기는 지워지지 않고 계속 쌓입니다.
  4. 시트에 올리기 — 장부에서 시트에 아직 없는 새 글만 골라 맨 아래에 추가. 기존 줄은 절대 안 건드림.

새 컴퓨터에 설치하기

순서대로 따라 하면 30분~1시간이면 끝납니다. 명령은 전부 복사해 붙여넣기 (실행법: ☀️ 탭 3번). 막히면 Claude Code에 "설치 이어서 도와줘"라고 하세요.

  1. 프로젝트 폴더 받기 — 전임자에게 받은 폴더를 원하는 위치에 두기 (예: C:\Users\내이름\Agent\trend-monitoring-agent).
  2. 비밀 파일 넣기 — 1:1로 받은 .env·gcp_sa.json을 폴더 맨 위에, (받았다면) trends.db·src\data 폴더도 제자리에.
  3. 실행 환경 설치 — 아래 세 줄을 순서대로: 
    python -m venv venv
venv\Scripts\pip.exe install -r requirements.txt
venv\Scripts\playwright.exe install chromium
  4. 캐릿 기기 등록 — 1-A절의 절차 그대로 (제일 까다로운 단계).
  5. 시험 운전 — 전체를 한 번 수동 실행하고, 시트에 잘 올라가는지 확인: 
    venv\Scripts\python.exe src\core\run_daily.py
  6. 매일 아침 8시 자동 실행 등록 — 관리자 권한 PowerShell에서, 첫 줄의 경로만 실제 폴더 위치로 바꿔 실행: 
    $ROOT = "C:\Users\<내이름>\Agent\trend-monitoring-agent"
$PY = "$ROOT\venv\Scripts\python.exe"
schtasks /Create /F /TN FF-Trend-Daily /SC DAILY /ST 08:00 /TR "`"$PY`" `"$ROOT\src\core\run_daily.py`""
  7. 다음날 아침 확인 — 시트에 오늘 날짜 새 줄이 있으면 성공. 전임자 컴퓨터의 자동 실행은 꺼달라고 요청 (schtasks /Delete /F /TN FF-Trend-Daily).
기억할 것: 자동 실행은 아침 8시에 컴퓨터가 켜져 있고 로그인된 상태여야 돕니다. 꺼뒀던 날은 다음 실행 때 최근 3주치에서 놓친 글을 알아서 보충합니다.

바꿀 수 있는 설정들

무엇을 바꿀 수 있고, 직접 할 수 있는지 / AI에게 부탁할 일인지로 정리했습니다. AI에게 부탁 = 프로젝트 폴더에서 Claude Code를 열고 표의 문장을 그대로 말하면 됩니다.

시트 관련 규칙 (다시 한 번)

  • 자동 칸 A~N: 순서 바꾸기·중간 삭제 금지. 사람 칸(메모 등)은 O열부터 오른쪽으로 자유롭게.
  • 여러 사람 컴퓨터에서 같은 시트에 올려도 안전합니다(중복 확인 후 추가). "수집자" 칸으로 누가 모았는지 구분돼요.
  • AI 요약이 만든 내용이 마음에 안 들면 시트에서 직접 고쳐도 됩니다 — 시스템이 덮어쓰지 않아요.

보안 규칙

  • 캐릿은 유료 콘텐츠 — 모은 본문은 내부 분석용으로만. 외부 공유·원문 복사 금지. (그래서 시트에도 본문 전문은 안 올라갑니다)
  • .env·gcp_sa.json은 비밀 열쇠 — 이메일·단체방 전송 금지, 주고받을 땐 1:1로만.
  • 시트 공유 목록의 로봇 계정(...iam.gserviceaccount.com) 삭제 금지.
  • 인계가 끝나면 전임자가 할 마무리: 자기 컴퓨터의 자동 실행 끄기 → 캐릿 기기 목록에서 자기 컴퓨터 삭제 → (계정을 넘겼다면) 비밀번호 변경.
