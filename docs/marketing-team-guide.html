Trend
Monitoring Agent

무엇이 뜨고 있는가, 매일 9시 슬랙으로 받습니다.

01목적 · Why

왜 만들었나

트렌드가 "떴다"고 알게 됐을 때는 이미 한 박자 늦어요. 그렇다고 캐릿·검색 트렌드를 매일 사람이 다 훑는 것도 비효율이고요. 일찍 + 선별 + 자동, 이 세 가지를 한 번에 푸는 게 목표였습니다.

트렌드는 떴을 때 잡으면
한 박자 늦다. 일찍 + 선별해서
받는 게 핵심이다.
— 프로젝트 시작 메모

풀고 싶었던 3가지

  • 01 시점 캐릿 큐레이션이 정리해주길 기다리지 말고 미세트렌드부터 잡기
  • 02 선별 전부 보지 말고 F&F 브랜드·타깃에 맞는 것만 골라내기
  • 03 노력 매일 손 안 대고 알아서 다이제스트가 도착하게

결과

매일 09:00에 슬랙 채널로 "오늘의 F&F 트렌드 다이제스트"가 자동으로 도착합니다.

카드 형식 — 무엇(기사 요약) → 왜 뜨나(부상 이유) → F&F 포인트(어느 브랜드에 어떻게 적용)

상위 트렌드 → 함께 볼 신호 → 참고 레퍼런스 → 패스 → 모니터링 포인트 순으로 한눈에 스캔.

02과정 · Process

어떻게 만들었나

4단계로 만들었습니다. 각 단계는 독립적이라 한 단계만 바꾸거나, 다른 프로젝트에 따로 떼서 쓸 수 있어요.

Phase 0

환경 구축

Hermes Agent(파이썬 AI 에이전트 런타임) + Claude(Anthropic Sonnet 4-6) API 연결.

Phase 1

수집기

Playwright로 캐릿 로그인 유지. 전용 프로필을 캐릿의 "등록된 기기" 1개로 만들어 매일 무인 접속.

Phase 2

점수화

Claude가 F&F 6기준(시점·실행가능성·카테고리·브랜드·타깃·리스크)으로 카드형 다이제스트 생성.

Phase 3

자동화

Windows 작업 스케줄러로 매일 09:00 무인 실행. 슬랙 incoming webhook으로 발송.

※ 가장 까다로웠던 건 1단계 — 캐릿이 동일 계정 4기기 제한 + 신규기기 이메일 OTP로 자동화 브라우저를 막아둬요. 결국 사용자가 OTP 번호 한 번만 알려주면 스크립트가 기기 삭제→인증번호 발송→입력→등록까지 자동으로 처리하는 흐름으로 풀었습니다.

교차검증의 힘

같은 트렌드가 여러 소스에 동시에 잡히면 다이제스트에 [전광판+네이버쇼핑] 같은 태그가 붙어요.

예) 캐릿 전광판이 잡은 젤리슈즈 꾸미기가 네이버 패션잡화 인기검색어에도 등장 → 실제 구매 수요까지 확인된 진짜 신호.

웹 검색 보강

캐릿 전광판은 트렌드 이름만 있고 본문이 없을 때가 많아요(예: "슬래커 코어"). 이런 미세트렌드는 Claude가 웹 검색으로 실제 자료를 찾아 "무엇/왜 뜨나"를 채워요. 출처 도메인까지 표기.

검색해도 못 찾으면 추측 안 하고 확인 필요로 정직하게 처리.

04예외 로직 · Filter

광고는 어떻게 거르나

트렌드 사이트에는 광고·협찬·자사 홍보가 섞여 있어요. 자동으로 걸러내려고 3중 안전장치를 깔았습니다.

01

소스 단계 — 기사만 본다

캐릿에서 수집하는 건 "/숫자" 형태의 기사 링크뿐. 디스플레이 배너 광고나 자체 홍보 블록("2026 캐릿 트렌드 프리뷰 위크" 같은 것)은 기사가 아니라 다른 형태라서 애초에 수집되지 않습니다.

캐릿 트렌드 레터(뉴스레터)는 별도 페이지라 수집 대상이 아님 → 거기 들어있는 협찬 섹션(예스24 리딩런·스킨푸드 PDRN 광고)도 자동으로 빠짐. 실제 수집된 데이터 grep 검증 결과 광고성 글 0건.

02

AI 판별 — 협찬·홍보성은 "패스"

점수화 단계의 Claude에게 명확히 지시: 광고·협찬·순수 홍보성(브랜드 보도자료·PR) 콘텐츠는 트렌드가 아니므로 "이번엔 패스"로 묶어라. 만에 하나 광고성 기사가 섞여도 다이제스트에서 자동으로 빠집니다.

단 "장원영 ETF 광고 비하인드"처럼 광고·마케팅을 분석한 에디토리얼은 그대로 트렌드 콘텐츠로 유지 — 광고에 대한 분석은 곧 트렌드 정보니까요.

03

무관 신호 필터 — 잡음 제거

Google Trends에는 주식 종목코드(005930)·정치인물명·사건사고처럼 F&F와 무관한 급상승 검색어가 많이 떠요. 이건 자동으로 "이번엔 패스"로 분류되고, 패션·뷰티·셀럽·상품·중국 같이 F&F 관련인 것만 다이제스트에 올라옵니다.

네이버 데이터랩도 마찬가지 — "티셔츠"·"샴푸" 같은 상시 일반 키워드는 패스, 급상승·신규·브랜드명·특이 아이템만 해석하도록 규칙화.

05목적 · Why

어디에 투자할까

트렌드 모니터링이 "지금 무엇이 뜨는가"를 본다면, 마켓 리서치는 "어느 브랜드·기업을 살까/주목해야 할까"를 봅니다. F&F 그룹 전체(패션·뷰티·엔터) 관점에서 경쟁사·시장·인수 후보의 주가·재무·뉴스·시그널을 상시 모니터링해, M&A 매력도와 투자 인사이트를 자동으로 도출합니다.

F&F 그룹 전체를 하나의
포트폴리오로 본다.
패션 · 뷰티 · 엔터의 시너지로.
— 분석 기본 원칙

F&F 그룹 정체성 (분석 기준점)

  • 엔터 F&F Entertainment (콘텐츠 IP · 아티스트)

왜 일반 리서치 대시보드와 다른가

  • 관점 항상 "F&F 그룹 관점"으로 분석 — 단순 데이터 나열 X
  • AI Claude가 뉴스·재무·시장 데이터에서 시그널을 자동 추출 (감성 분석 포함)
  • 지역 한국·중국·북미·유럽·일본·동남아·남미 — 지역별 별도 모니터링

07결과물 · Output

무엇이 나오나

자체 대시보드부터 슬랙 정기 리포트까지 — 분석 결과를 매일·매주 자동으로 받아볼 수 있게 만들었습니다.

A

워치리스트 대시보드

관심 브랜드·기업별 KPI를 한눈에 — 주가 · 시총 · PER · 뉴스 시그널 · M&A 점수. 정렬·필터·드릴다운 가능. (Next.js + shadcn/ui)

B

AI 브랜드 자동 등록

워치리스트에 브랜드 이름만 넣으면 재무·뉴스·시장 데이터가 자동 수집·채워집니다. 사람이 일일이 검색·정리할 필요 없음.

C

뉴스 피드 · AI 태깅

자동 수집된 뉴스를 Claude가 감성·M&A 시그널·이벤트로 자동 태깅. 의미 있는 시그널만 위로 올라와 중요한 흐름을 놓치지 않아요.

D

슬랙 봇 · 정기 리포트

임계치 넘는 시그널(주가 급변동 · 이상 뉴스 · M&A 루머 · 신규 진입자)이 잡히면 슬랙 채널로 자동 푸시. 주간 종합 리포트도 정해진 시각에 발송.

※ 실제 활용 예시 — 새 K-뷰티 브랜드가 부상하는 시점에 매출·언급량·투자 라운드 신호를 자동 감지 → F&F 그룹의 포트폴리오 확장 인수 후보로 검토. 비상장 자회사(F&Co·F&F Ent.)는 공시 데이터가 제한적이라 웹 검색 중심 수집으로 보완.

08커스터마이징 · Tuning

내가 바꿀 수 있는 부분

이 두 에이전트는 F&F용으로 세팅된 템플릿이에요. 다른 회사·다른 산업이라도 거의 모든 부분이 설정값이라 아래 노브만 갈아끼우면 그대로 작동합니다. 코드를 새로 짜는 게 아니라, 검증된 템플릿을 우리 회사에 맞게 튜닝하는 거예요.

시작하는 3단계

처음 도입할 때 이 순서로 정하면 깔끔해요.

01

정체성 정의

우리 회사 브랜드·타깃·카테고리·경쟁사를 한 문서로 정리. 모든 분석의 기준점이 됨.

02

소스 결정

우리 산업·시장에 맞는 트렌드/뉴스/이커머스 사이트 선택. 무료 공개 소스부터 시작해 점진적 확장.

03

채널·주기 결정

누가 언제 어디로 받을지(매일 9시 슬랙 / 매주 월요일 이메일 등) 정하면 끝.

8개 노브 · 무엇을 바꾸나

각 노브마다 "다른 산업이라면 이렇게 적힐 거예요" 예시를 같이 적어뒀어요.
