이제 파일 주고받기(merge) 없이, 하나의 Notion DB를 둘이 같이 봅니다
  • 레이첼(웹 트렌드)·데이빗(SNS 트렌드)이 같은 Notion DB 한 곳에 데이터를 올려요
  • 같은 글은 article_id로 자동 중복 제거, 수집자 칸에 rachel/david 표시
  • merge 단계가 사라졌어요 — 각자 올리면 같은 표에 실시간으로 쌓이고, 둘 다 브라우저에서 봄

1단계 · 보기

같이 보고 활용하기 (설치 0)

위 링크로 들어가면 레이첼이 모은 트렌드가 표로 쌓여 있어요. 노션에서 바로:

  • 필터: 수집자 = david / 카테고리 = 패션 등
  • 정렬: DB등록일 최신순 → "요즘 새로 들어온 트렌드"
  • 보드뷰: 카테고리별 칸반으로 보기
여기까지는 데이빗이 아무것도 설치 안 해도 돼요. 트렌드를 받아보기만 한다면 1단계로 끝.
2단계 · 한 번만

내 데이터도 올리려면 — PC 세팅

1Python 설치

python.org/downloads → 설치 화면 "Add Python to PATH" 체크 ✅ (추가 설치 불필요)

2레이첼이 준 파일 3개를 폴더에 두기

아래 구조 그대로 만들어 주세요 (경로가 중요해요):

C:\트렌드\
   ├─ .env                      # 토큰/DB id (아래 4번)
   └─ src\service\
        ├─ trenddb.py           # 내 분석결과 → trends.db
        └─ notion_push.py       # trends.db → Notion 업로드

3PowerShell 열고 폴더로 이동 + 이름표 설정 (1회)

cd C:\트렌드
python src\service\trenddb.py set-owner david

4.env 파일 만들기 (메모장)

C:\트렌드\.env 에 아래 2줄 — 값은 레이첼에게 받기:

TEAM_NOTION_TOKEN=레이첼에게-받은-토큰
NOTION_TREND_DB_ID=37efd8bc-f558-81df-9475-c58ee6709c41
🔐 토큰은 비밀번호 같은 거예요 — 공개 채널에 올리지 말고 레이첼에게 1:1(DM)로만 받으세요.
3단계 · 올리기

내 트렌드를 Notion에 올리기

# 1) 내 SNS 분석결과(JSON 폴더)로 trends.db 만들기
python src\service\trenddb.py export --from "C:\내가\SNS분석결과JSON폴더"

# 2) Notion 공유 DB로 올리기
python src\service\notion_push.py

→ 끝! 노션 DB에 david 이름표로 글이 올라가요. 같은 글을 레이첼도 모았으면 한 줄로 합쳐지고 rachel, david 둘 다 표시됩니다.

⏳ 미팅에서 정할 것: 데이빗은 SNS(인스타·X·틱톡), 레이첼은 웹 기반이라 칸 구성이 달라요. 데이빗 전용 칸(조회수·좋아요·플랫폼 등)을 어떻게 담을지 공통 양식을 정한 뒤 레이첼이 맞춰줄 예정. 그 전엔 1단계(보기)만 해도 충분하고, 올리기는 미팅 후 확정해요.
