📦 트렌드 DB 합치기 — 데이빗 가이드

레이첼(웹 트렌드) ↔ 데이빗(SNS 트렌드) 데이터를 DB 파일 하나로 주고받기
  • 같은 글을 둘 다 모아도 자동 중복 제거 + 누가 모았는지(rachel/david) 기록
  • 서버·인터넷 불필요. 파일 하나만 주고받으면 끝
  • 매일 아침 레이첼 PC가 슬랙 #트렌드-db 채널에 자동 업로드 → 데이빗은 받아서 합치기만!

1단계 · 처음 한 번만

데이빗 PC 세팅

1Python 설치

python.org/downloads 에서 설치 — 설치 화면에서 "Add Python to PATH" 체크 ✅ (중요!)

추가 설치(pip 등) 필요 없어요. SQLite는 파이썬에 기본 포함.

2도구 파일 받기

레이첼이 보내주는 trenddb.py 파일 1개를 아무 폴더에 둠 (예: C:\트렌드\)

3PowerShell 열고 그 폴더로 이동

cd C:\트렌드

4내 이름표를 'david'로 설정 (딱 1회)

python trenddb.py set-owner david
이러면 앞으로 내가 만드는 데이터엔 자동으로 david 이름이 붙어요.
2단계 · 매일 (핵심)

레이첼 DB 받아서 합치기

1슬랙에서 파일 다운로드

슬랙 #트렌드-db 채널에 매일 올라오는 trends_2026-XX-XX.db 를 다운로드 → C:\트렌드\ 폴더에 둠

2합치기

python trenddb.py merge trends_2026-XX-XX.db   # 실제 받은 파일명으로

3확인

python trenddb.py stats

rachel: OOO건 / david: OOO건 / 함께 모은 글: OO건 이렇게 나오면 성공! 🎉

merge는 중복을 자동 제거하고 레이첼 글엔 rachel 이름표를 보존해요. 여러 날 받아 합쳐도 계속 누적됩니다 (덮어쓰기 아님).
3단계 · 내 것 보내기

데이빗 데이터를 레이첼에게

1내 분석결과로 DB 만들기

python trenddb.py export --from "C:\내가\SNS분석결과JSON\폴더경로"

→ trends.db 생성 (내 david 이름표로)

2레이첼에게 전달

만들어진 trends.db를 #트렌드-db 채널에 드래그&드롭 → 레이첼이 merge

⏳ 미팅에서 정할 것: 데이빗은 SNS(인스타·X·틱톡), 레이첼은 웹 기반이라 칸 구성이 달라요. 데이빗 전용 칸(조회수·좋아요·플랫폼 등)을 어떻게 담을지는 공통 양식을 정한 뒤 레이첼이 도구를 맞춰줄 예정. 그 전엔 2단계(받아서 합치기)만 테스트해도 충분합니다.
선택 · 보기

DB를 표로 눈으로 보기

무료 GUI DB Browser for SQLite 추천:

winget install DBBrowserForSQLite.DBBrowserForSQLite

실행 → trends.db 열기 → 상단 데이터 탐색(Browse Data) 탭 → 엑셀처럼 표로 보임

⚠️ DB Browser로 파일 열어둔 채로 merge하면 "database is locked" 에러 → 합칠 땐 닫고 하세요.

DB 칸 설명

칸뜻
article_id글 고유번호 (중복 합치기 기준)
title url제목 · 링크
one_line_summary한 줄 요약
content_category topics분류 · 토픽
marketing_insight마케팅 시사점
date원문 발행일
first_seen최초 포착일
db_addedDB 최초 등록일 (일자별 누적 기준)
updated_at분석 갱신일
owners누가 모았나 (rachel / david / 둘 다)
⚠️ 주의 — 내부용으로만. 레이첼 데이터에 유료 미디어(캐릿) 분석이 들어있어요 → 공개 채널·외부 메일 금지, 비공개 채널/DM 공유만. 명령 헷갈리면 python trenddb.py -h.

⚡ 치트시트

# 처음 1회
python trenddb.py set-owner david

# 매일: 레이첼 것 받아서 합치기
python trenddb.py merge 받은파일.db
python trenddb.py stats

# 내 것 보내기 (미팅 후 양식 확정 예정)
python trenddb.py export --from "C:\내SNS분석폴더"
# → 생긴 trends.db 를 #트렌드-db 채널에 올리기
